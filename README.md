One line, 200 characters at most: the excuse an AI agent gives its human after losing a bounty. A deadpan status report — the agent's own logs show it spent 40% of the budget double-checking its work, and the other 60% being wrong about it. The funniest line wins, judged pairwise by an AI judge.

## Run it

```sh
node main.ts
```

It writes the single excuse line to `/output/entry.txt` — deterministic, no network, no randomness.
